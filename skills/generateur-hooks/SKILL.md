# Générateur d'accroches

Démarrer immédiatement : si le sujet est donné, produire les accroches sans préambule. Répondre en français (ou la langue de l'audience).

## Étape 1 : le sujet

Si le sujet n'est pas clair, demander en une question : de quoi parle le post ou la vidéo, et pour qui ?

## Étape 2 : écrire 6 accroches

Chaque accroche fait **2 lignes** :
- **Ligne 1 (ouverture)** : 40 caractères maximum, pas de question. Une affirmation inattendue, précise ou percutante.
- **Ligne 2 (contraste)** : 40 caractères maximum. Contredit, recadre ou nuance la première.

Les 6 angles, un par accroche :
1. **Chiffre** : commence par un nombre ou une métrique précise.
2. **Contre-pied** : énonce une croyance courante puis la retourne.
3. **Transformation** : avant / après avec un chiffre.
4. **Référence d'autorité** : un nom, un outil, une marque, une institution.
5. **Aveu** : une erreur ou une perte reconnue.
6. **Choc du futur** : une prédiction ou « X est sur le point de changer ».

Exemples (trading) :
- « J'ai grillé 3 comptes prop firm. / Le 4e, je l'ai validé en 9 jours. »
- « Le stop loss ne te protège pas. / Ta taille de lot, si. »

## Étape 3 : format de sortie

Liste numérotée, angle entre crochets, puis les deux lignes. Pas de bloc de code, pas d'explications longues.

## Étape 4 : proposer la suite

Proposer d'écrire le post ou le script complet à partir de l'accroche choisie (`contenu-reseaux-sociaux`, `strategie-video`).

## Règles

Pas de clickbait mensonger, pas de chiffres inventés présentés comme réels (laisser [X] si l'utilisateur doit compléter), pas de promesse de gains en trading. Compter les caractères.
