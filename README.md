# Merex Skills FR

Collection de **26 skills Claude en français** pour les créateurs, formateurs et traders francophones : trading, marketing, media buying, data, design, copywriting, vidéo, réseaux sociaux et SEO.

**Traduite, adaptée et organisée par Merex Academy** à partir des meilleurs projets open source de la communauté (voir [CREDITS.md](CREDITS.md)). Chaque skill a été relu, traduit, adapté au contexte francophone et au trading (règles de conformité publicitaire, prop firms), et débarrassé des dépendances à des clés d'API payantes.

## Installation

- **Claude (app / Cowork)** : installer le fichier `.plugin`, ou ajouter ce dépôt comme plugin.
- **Claude Code** : `/plugin marketplace add <votre-compte>/merex-skills-fr` puis installer `merex-skills-fr`, ou copier les dossiers de `skills/` dans `~/.claude/skills/`.

## Structure

Chaque skill contient :
- `SKILL.md` : la version française adaptée (c'est elle que Claude utilise) ;
- `references/original-en.md` : le texte d'origine, pour référence ;
- `references/`, `scripts/`, `assets/`, `data/` : les ressources d'origine (en anglais), utilisées par la version française.

## Avertissement

Les skills liés au trading sont des outils éducatifs et d'aide à la discipline. Ils ne constituent pas un conseil en investissement. Le trading comporte un risque de perte en capital.
